# Java Practitioner Craftsmanship and Conference Insights

## Use when
- mining talks/books/articles for QA-relevant lessons,
- extracting insights from Venkat, Goetz, Marks, Paumard, Parlog, Shipilev and similar practitioners,
- translating conference material into project/testing implications.

## Extract
- main idea,
- anti-pattern,
- practical heuristic,
- impact on code quality,
- impact on testability,
- project application,
- relation to Effective Java,
- interview-ready insight.

## When Not to Use
Do not use this for exact framework-version decisions or unsupported claims about speakers.

See `references/conference-insight-note.md`.
