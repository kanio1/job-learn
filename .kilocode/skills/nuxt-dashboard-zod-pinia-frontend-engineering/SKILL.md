# Nuxt Dashboard, Zod and Pinia Frontend Engineering

## Use when
- designing dashboard pages/routes/forms,
- deciding Zod schemas and Pinia stores,
- reviewing frontend testability,
- explaining UI architecture to a tester.

## When Not to Use
Do not use this for E2E framework mechanics, backend authorization policy or pure API testing.

See `references/frontend-testability-checklist.md`.
