# Public Skill Adoption Checklist

Before adopting or adapting:
- Is the repo active?
- Is the source credible?
- Is the license acceptable?
- Are there scripts? What do they do?
- Are there external calls or shell commands?
- Does the skill solve a real project need?
- Is it redundant with existing skills?
- Should we adapt rather than copy?
- Should it become a reference, not a skill?
