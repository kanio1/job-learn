# Phase 1 — Foundations (Lessons 1-5)

These lessons are prerequisites for Lesson 6+. You should understand them but do NOT need to re-study them during active learning.

## Lesson Overview

| Lesson | Topic | Key Learning |
|---|---|---|
| 01 | REST API Request/Response Flow | HTTP method, endpoint, status codes, request/response body |
| 02 | REST Assured — What It Is | `given().when().then()`, simple assertions |
| 03 | REST Assured Foundations | HTTP method, endpoint, content-type basics |
| 04 | Path Params, Query Params, Headers | `Authorization`, `X-Correlation-ID`, input channels |
| 05 | Request Body, JSON, Map.of, DTO Serialization | Request body construction, `Map.of`, DTOs |

## Foundation Technologies

| Area | What You Know |
|---|---|
| REST Assured | `given()/when()/then()`, path params, query params, headers, JSON body |
| HTTP/REST | Method semantics, status codes, request/response flow |
| Java 25 | Records, enums, collections, `java.time` |
| Spring Boot | Controller, DTO, validation, binding |
| AssertJ | Basic assertions, `extracting` |
| JUnit | `@Test`, test lifecycle |
| Test Design | BVA, EP, state transitions, decision tables |
