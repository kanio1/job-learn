# Backend Testing Review - MOC

This area contains practical review tools for backend API tests and backend architecture changes that affect testability.

## Main Checklist

- `Professional Backend API Testing Reviewer Checklist.md`

## When To Use It

Use the checklist when reviewing:

- REST Assured tests.
- Security tests around 401/403.
- API negative tests and error contracts.
- Refactoring that changes controller, service, domain or repository responsibilities.
- Maven/JDK/test tooling changes that affect build stability.
- Deferred risks after a green build.
