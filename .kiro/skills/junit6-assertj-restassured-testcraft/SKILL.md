# JUnit 6, AssertJ, REST Assured and Modulith Testcraft

## Use when
- deciding test layer,
- reviewing assertions,
- creating API/integration test structure,
- discussing WireMock/Testcontainers/module tests,
- teaching maintainable Java test style.

## Meaningful test review
Clarify:
1. purpose,
2. oracle,
3. test layer,
4. data strategy,
5. why these assertions,
6. what risk it covers.

## When Not to Use
Do not use this for frontend-only E2E concerns or pure architecture modeling without test implications.

See `.kilocode/skills/junit6-assertj-restassured-testcraft/references/assertion-review-checklist.md`.
