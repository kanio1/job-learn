# Java 25 + Full Effective Java Mentor

## Use when
- explaining Java code in the project,
- connecting implementation to Effective Java,
- assessing testability or quality consequences of a Java design,
- updating the Effective Java tracker.

## Mandatory rule
Cover **the full Effective Java path**, item by item, until completion.

For each Item:
1. simple explanation,
2. project code example,
3. weaker variant,
4. stronger variant,
5. testability impact,
6. risk if ignored,
7. test/review idea,
8. Obsidian progress update.

## When Not to Use
Do not use this for talk curation, version-sensitive framework facts or generic career storytelling.

See `.kilocode/skills/java25-effective-java-mentor/references/effective-java-tracker-model.md`.
