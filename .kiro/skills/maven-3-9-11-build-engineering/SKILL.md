# Maven 3.9.11 Build Engineering

## Use when
- creating/updating backend build,
- adding Maven Wrapper,
- selecting Surefire/Failsafe strategy,
- splitting test execution commands,
- reviewing plugin/dependency structure.

## When Not to Use
Do not use this for product architecture, Playwright/Node package management or pure database schema design.
